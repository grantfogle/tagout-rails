# Calendar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show signed-in users the next 30 days of hunting dates on the home page, plus a `/calendar` page covering the next 12 months, with CPW dates, season dates and personal reminders.

**Architecture:** One `calendar_events` table holds public events (`user_id` NULL, loaded from checked-in YAML by a rake task) and personal reminders (`user_id` set). `CalendarService` (same pattern as `HuntStatsService`) returns the 30-day list and the month-grouped year. Controllers stay thin.

**Tech Stack:** Rails 6.1, Ruby 3.1.3, Postgres, Minitest + fixtures (`users(:alice)`, `users(:bob)`), Devise, SCSS under `app/assets/stylesheets/components/`.

**Spec:** `docs/superpowers/specs/2026-10-30-calendar-design.md`

## Global Constraints

- Public events live in `db/calendar/<year>.yml`, NOT `db/seeds/` (`db/seeds/*` is gitignored).
- `calendar_events.state` defaults to `CO` and is validated against `Profile::STATES.keys`; only `CO` data is loaded now.
- `species` is nullable (NULL = applies to all) and validated against `HuntStat::SPECIES_OPTIONS`.
- No DB unique index on events (NULL `species` defeats it); the loader enforces uniqueness with `find_or_initialize_by`.
- Species filter precedence: explicit `species:` argument, then profile `favorite_species` if non-empty, then all species.
- Users can only edit or delete their own reminders; public events are never editable through `calendar_events`.
- Year view is month sections as lists, not a day grid.
- Out of scope: recurring reminders, notifications, iCal export, admin UI.
- Every commit message ends with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (use a second `-m` flag as shown).
- Date-dependent tests use `travel_to Time.zone.local(2026, 10, 31, 12)` so they don't rot.

```ruby
# app/models/calendar_event.rb
class CalendarEvent < ApplicationRecord
  KIND_LABELS = {
    "deadline" => "Deadline",
    "draw_results" => "Draw results",
    "leftover" => "Leftover licenses",
    "season" => "Season",
    "reminder" => "Reminder"
  }.freeze
  KINDS = KIND_LABELS.keys.freeze

  belongs_to :user, optional: true

  before_validation { self.species = species.presence }

  validates :title, presence: true
  validates :starts_on, presence: true
  validates :kind, inclusion: { in: KINDS }
  validates :state, inclusion: { in: Profile::STATES.keys }
  validates :species, inclusion: { in: HuntStat::SPECIES_OPTIONS }, allow_nil: true
  validate :ends_on_not_before_starts_on
  validate :user_matches_kind

  scope :between, ->(from, to) { where("starts_on <= ? AND COALESCE(ends_on, starts_on) >= ?", to, from) }
  scope :visible_to, ->(user) { where(user_id: [nil, user.id]) }
  scope :for_species, ->(list) { list.blank? ? all : where(species: [nil, *list]) }
  scope :chronological, -> { order(:starts_on, :id) }

  private

  def ends_on_not_before_starts_on
    return if ends_on.blank? || starts_on.blank?
    errors.add(:ends_on, "can't be before the start date") if ends_on < starts_on
  end

  # Reminders belong to a user; every other kind is a public event.
  def user_matches_kind
    return if (kind == "reminder") == user_id.present?
    errors.add(:user, kind == "reminder" ? "is required for reminders" : "must be blank for public events")
  end
end
```

```ruby
# app/services/calendar_service.rb
class CalendarService
  def initialize(user, today: Date.current)
    @user = user
    @today = today
  end

  # Events from today through `days` days out, soonest first.
  def upcoming(days: 30)
    scoped(nil).between(@today, @today + days).chronological
  end

  # The next 12 months as { first_of_month => [events] }. An event is filed under
  # the month it starts in, or the current month if it started earlier (a season
  # already underway).
  def year(species: nil, mine_only: false)
    months = Array.new(12) { |i| @today.beginning_of_month >> i }
    events = scoped(species).between(@today, months.last.end_of_month).chronological
    events = events.where(user_id: @user.id) if mine_only

    buckets = months.index_with { [] }
    events.each { |event| buckets[[event.starts_on, @today].max.beginning_of_month] << event }
    buckets
  end

  private

  def scoped(explicit_species)
    CalendarEvent.visible_to(@user).for_species(species_list(explicit_species))
  end

  def species_list(explicit)
    return [explicit] if explicit.present?

    @user.profile&.favorite_species.presence
  end
end
```

```ruby
# app/services/calendar_loader.rb
# Loads public (non-user) calendar events from db/calendar/*.yml. Idempotent: an
# event is matched on state/kind/species/starts_on/title and updated in place.
class CalendarLoader
  def self.default_paths
    Dir[Rails.root.join("db/calendar/*.yml")].sort
  end

  def self.call(paths = default_paths)
    paths.sum do |path|
      data = YAML.safe_load(File.read(path), permitted_classes: [Date]) || {}
      Array(data["events"]).each { |row| upsert(row) }.size
    end
  end

  def self.upsert(row)
    event = CalendarEvent.find_or_initialize_by(
      state: row.fetch("state", "CO"), kind: row["kind"], species: row["species"].presence,
      starts_on: row["starts_on"], title: row["title"], user_id: nil
    )
    event.assign_attributes(ends_on: row["ends_on"], notes: row["notes"])
    event.save!
  end
  private_class_method :upsert
end
```

```ruby
# app/controllers/calendar_events_controller.rb
class CalendarEventsController < ApplicationController
  before_action :authenticate_user!
  # Scoped to the current user, so other people's reminders and all public
  # events raise RecordNotFound (404).
  before_action :set_event, only: [:edit, :update, :destroy]

  def new
    @event = current_user.calendar_events.build(starts_on: Date.current)
  end

  def create
    @event = current_user.calendar_events.build(event_params.merge(kind: "reminder", state: "CO"))
    if @event.save
      redirect_to calendar_path, notice: "Reminder added."
    else
      render :new, status: :unprocessable_entity
    end
  end

  def edit; end

  def update
    if @event.update(event_params)
      redirect_to calendar_path, notice: "Reminder updated."
    else
      render :edit, status: :unprocessable_entity
    end
  end

  def destroy
    @event.destroy
    redirect_to calendar_path, notice: "Reminder deleted."
  end

  private

  def set_event
    @event = current_user.calendar_events.find(params[:id])
  end

  def event_params
    params.require(:calendar_event).permit(:title, :species, :starts_on, :ends_on, :notes)
  end
end
```
